How to use DumpKeeper

1Add database
2Add destination
3Create backup job
4Back up & restore

Add database

Open Databases and click Add database. Fill in the host, port, database name, and credentials, then save.

Use the address as seen from the DumpKeeper container, not localhost. Click Ping to verify the connection.

Add destination

Backups are always kept in local storage. To also send them to S3-compatible storage, open Destinations and add the endpoint, access keys, and bucket.

You can add as many destinations as you want and pick several for one job.

Create backup job

Open Jobs and click Add job. Choose the database and destinations, set a five-field cron schedule, and pick how many backups to keep.

Leave the schedule empty for manual backups only.

Back up & restore

Run a job any time with Back up now, or wait for the schedule. Results appear under Executions.

Restore any saved dump — or upload your own SQL file — from the Restore page.
